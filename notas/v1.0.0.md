## Tempia 1.0.0 — primera versión

Monitor de hardware para Windows creado por **Boldo3108**.

- 🌡️ Temperatura y uso de **CPU** y **GPU** (hotspot, VRAM, potencia, relojes), RAM, discos y red
- 🌀 **Ventiladores**: ver RPM y controlarlos (Automático / Manual / Curva) con protecciones de seguridad
- ▣ **Modo mini** configurable, flotante sobre juegos y OBS
- ⚙️ Configuración: elegir qué se muestra, alertas, °C/°F
- ⬆️ Actualizaciones automáticas desde GitHub

**Importante:** para ver la temperatura del CPU, la placa madre y los ventiladores instala el driver gratuito
[PawnIO](https://pawnio.eu/) y reinicia el PC. Tempia pide permisos de administrador al abrirse.
